# PocketCloud

Personal cloud storage and automatic phone backup app.

**Student:** Aseer Ahmed (B24F1446SE019)
**Course:** Mobile Application Development

## Features (planned)
- Select folders on the phone for backup
- Backup queue and history
- QR code pairing with laptop
- Restore files from the laptop

## Tech stack
Python, Kivy, SQLite, FastAPI

## Setup
1. Install Python 3.12
2. `py -3.12 -m venv venv`
3. `venv\Scripts\activate`
4. `pip install kivy`
5. `python mobile/main.py`
